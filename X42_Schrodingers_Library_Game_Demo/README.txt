X42 SCHRODINGER'S LIBRARY — ONE-SHEET GAME DEMO

Open index.html in a modern browser.

CONTROLS
- Touch: drag the circular remote / joystick
- Keyboard: WASD or arrow keys
- Space: attack
- ATTACK: cycles the Bunny attack cells from the supplied one-sheet
- SKILL: cycles skill cells and consumes Focus
- INTERACT: dialogue
- CHAPTERS: music-style story selector
- ONE SHEET: inspect the source atlas
- EXIT: return to chapter menu

ARCHITECTURE
The supplied one_sheet.png is the source of truth. Runtime Bunny animation reads atlas
coordinates from that image instead of loading separately exported character PNGs.
The demo is intentionally self-contained: no framework, build step, server, or external CDN.

NOTE
The atlas coordinates in app.js are deliberately explicit so an editor can later replace
them with coordinates generated by an automatic sheet scanner/manifest.
